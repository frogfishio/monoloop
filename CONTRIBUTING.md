# Contributing

Monoloop does **not** accept external contributions.

Bug reports, questions, and suggestions are welcome (for example via the
project issue tracker). Pull requests and any contributed code,
documentation, tests, designs, or other copyrightable material are **not**
accepted.

This policy keeps ownership unambiguous so that Monoloop can be offered under
the AGPL-3.0-or-later and, separately, under a commercial license from
[frogfish.io](https://frogfish.io). See `LICENSING.md`.

Please do not open pull requests. If you have a bug report or suggestion,
describe it without attaching patches you expect to be merged.
